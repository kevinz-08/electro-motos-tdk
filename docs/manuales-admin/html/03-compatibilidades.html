Compatibilidades

/admin/compatibilidades

Define qué repuesto le sirve a qué moto. Aquí se dan de alta los modelos de moto, se importan compatibilidades en bloque desde un CSV y se ve cuántas compatibilidades verificadas tiene cada modelo. Solo lo verificado se publica; ante la duda, déjalo sin verificar: una compatibilidad equivocada genera una devolución.

1. Cómo está organizada la pantalla

BloquePara qué sirve
Importar desde CSVCarga muchas compatibilidades de una vez desde un archivo.
Nuevo modelo de moto / Editar modeloÚnico lugar donde se crean modelos (marca + modelo).
Tabla de modelosVerificadas, pendientes y si el modelo ya tiene página ("hub") pública.

2. Dar de alta un modelo de moto

  1. En Nuevo modelo de moto escribe la Marca (se crea si no existe) y el Modelo sin la marca. Ej.: marca AKT, modelo NKD 125.
  2. cc, año desde y año hasta: llénalos solo si están confirmados. Vacíos, la web no los muestra.
  3. Alias: cómo lo escribe la gente al buscar ("NKD", "AK125NKD"), separados por comas. También sirven para que el CSV reconozca el modelo.
  4. Introducción del hub (opcional): texto escrito por una persona (máx. 2000 caracteres) que aparece en la página del modelo.
  5. Pulsa Crear modelo.

Editar: en la tabla pulsa Editar junto al modelo; el formulario sube con los datos. La marca no se puede cambiar y el slug se conserva (cambiarlo rompería la URL del hub ya indexada). Cancelar edición descarta los cambios.

3. Importar compatibilidades por CSV

  1. Pulsa Plantilla y descarga el CSV de ejemplo. Ábrelo en Excel.
  2. Llena una fila por compatibilidad. Columnas: sku, marca_moto, modelo_moto, posicion, anio_desde, anio_hasta, fuente, notas, verificado.
  3. Reglas: fuente obligatoria; posicion = delantera, trasera o ambas; verificado = si o no. Solo las filas con verificado = si se publican.
  4. Pulsa Subir CSV y elige el archivo.
  5. Revisa el reporte: nuevas · actualizadas · publicables · con error. Cada error indica la línea y el motivo. Corrige esas filas y vuelve a subir.
El importador no crea modelos. Si el modelo de una fila no existe, esa fila se rechaza: primero créalo (sección 2) o agrega ese nombre como alias de un modelo existente.

4. Leer la tabla de modelos

  • Filtro: escribe marca, modelo o alias para encontrarlo.
  • Verificadas (verde) = publicadas. Pendientes (ámbar) = cargadas pero sin verificar.
  • Hub: "Ver" abre la página pública del modelo. "Sin publicar" = el modelo no tiene ninguna verificada (o está inactivo) y no tiene página propia.

Un solo producto: ábrelo en /admin/productos → "Compatibilidades" (se guarda al instante). Cada cambio aquí actualiza solo la tienda; no hace falta "Refrescar tienda".
