Kits

/admin/kits

Un kit agrupa varios productos que se compran juntos (por ejemplo, el cambio de aceite completo) con un descuento opcional. El kit no tiene stock propio: su precio y su disponibilidad se calculan siempre a partir de los productos que lo componen.

1. La lista de kits

Columnas: Kit, Moto, Productos (cantidad), Precio (con el precio sin descuento tachado), Disponibilidad (cuántos kits se pueden armar hoy con el stock actual) y Estado (punto verde = activo). El botón Nuevo kit crea uno; "Editar" abre el existente.

2. Crear un kit (paso a paso)

  1. Pulsa Nuevo kit.
  2. Completa los datos generales (tabla).
  3. En Productos del kit busca por nombre o SKU y agrégalos. Define la cantidad (Cant.) de cada uno.
  4. Escribe el descuento si lo hay y revisa el resumen de precio a la derecha/abajo.
  5. Pulsa Crear kit (o Guardar cambios si editas).
CampoQué escribir / regla
Nombre del kit *Ej. "Kit de mantenimiento NKD 125".
Slug (URL) *Ej. kit-mantenimiento-nkd-125.
DescripciónOpcional. Ej. "Para el cambio de aceite completo, incluye filtro y bujía."
Modelo de motoOpcional: agrupa el kit en la página de esa moto. "Kit genérico" = sin moto asociada.
Kit activoVisible en la tienda solo si además tiene disponibilidad.
Productos del kitMínimo 2, máximo 8 productos distintos.
Descuento del kit (COP)En pesos. 0 = sin descuento: el precio es la suma de los productos. Debe ser menor que la suma.

3. El resumen de precio

Muestra Suma de productos, Descuento, Precio final del kit y Disponibilidad hoy. Si dice "sin stock (no se mostrará)", algún producto está agotado o inactivo y el kit no aparece en la tienda hasta que se reponga. Los productos con problema se marcan en ámbar como Inactivo o Agotado.

4. Cómo compra el cliente

Al agregar el kit al carrito se convierte en líneas normales de cada producto. El pago, el stock y los envíos funcionan igual que con productos sueltos.

5. Eliminar un kit

"Zona de peligro" → Eliminar → confirmar. El kit se retira de la tienda y se desactiva; los productos que lo componían no se tocan.

Ojo: si cambias el precio de un producto, el kit cambia solo (nunca se guarda un precio fijo). Si el nuevo precio hace que el descuento iguale o supere la suma, el servidor rechaza el guardado: baja el descuento.
