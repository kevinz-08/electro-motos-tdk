# GEO — material fuera del sitio (Fase 6)

Lo técnico de la Fase 6 está en el código (ver [`../06-geo.md`](../06-geo.md)). Esta carpeta es lo que **prepara el
agente y ejecuta el equipo de H2R**.

| Archivo | Qué es | Tarea |
|---|---|---|
| [`guiones-video.md`](./guiones-video.md) | 10 guiones de vídeo corto sobre productos y motos reales del catálogo | H-29 |
| [`correos.md`](./correos.md) | Plantillas para medios (Índice de Precios), blogs, talleres y marcas proveedoras | H-30 |
| [`comunidades.md`](./comunidades.md) | Reglas, tono y respuestas modelo para grupos y foros por modelo | H-31 |
| [`perfiles-marca.md`](./perfiles-marca.md) | Datos canónicos y checklist de perfiles (Google Business, Bing Places, directorios…) | H-41, H-42 |
| [`prompts.md`](./prompts.md) | 30 prompts reales y registro mensual — **la línea base es el criterio de salida** | H-32 |
| [`medicion-trafico-ia.md`](./medicion-trafico-ia.md) | Cómo ver en GA4 las visitas que llegan desde asistentes de IA | H-45 |

**Orden sugerido:** (1) `prompts.md` — medir la línea base **antes** de hacer lo demás, o no se sabrá qué cambió;
(2) `perfiles-marca.md`; (3) `comunidades.md`, que es continuo; (4) vídeos y correos, que dependen de tener guías
publicadas y el primer corte del Índice de Precios.
